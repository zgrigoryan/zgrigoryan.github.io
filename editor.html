First-time setup
  1. Open GitHub’s token settings.
  2. Select only zgrigoryan.github.io under repository access.
  3. Set repository Contents permission to Read and write, choose an expiry, and generate the token.
  4. Paste it above. You’ll need it again after refreshing this editor.
